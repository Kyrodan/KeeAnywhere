## Data Usage, Advertisements, Costs
KeeAnywhere and me - the author - respects your privacy. I do not collect, store, transmit or use any of your data. KeeAnywhere is free from advertisements. You can use KeeAnywhere free of any costs or license fees.

## Granting Access
To grant KeeAnywhere access to your cloud provider, KeeAnywhere opens the login page of your cloud provider in your default web browser, where you enter your username and password. KeeAnywhere never sees the entered username and password - they are neither used nor stored by KeeAnywhere in any way in any place. If you log in to your cloud provider and allow KeeAnywhere to access your data, a unique access token is created and transmitted to KeeAnywhere. This access token needs to be stored for loading and saving your files (especially your KeePass Password Safe databases). The storage location and encryption level for this access token depends on your selection of the account storage location. Use 'Local User Secure Store' for maximum possible security. For most storage providers the access token has a limited validity and expires after a time period if not used. It is also possible to revoke access for KeeAnywhere in all cloud providers. For details please check the documentation of your cloud provider.

For storage providers using access keys instead of a login (e.g. Amazon S3, Azure, Google Cloud Storage), the entered keys are stored in the same way as the access tokens.
